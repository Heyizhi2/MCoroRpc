```
flowchart TD
    A[调用 channel->close] --> B[原子交换 isActive_ false]
    B --> C[调用 cleanup]
    C --> D[加锁 mutex_]
    D --> E[遍历 writers_ 链表]
    E --> F[对每个 WriterAwaiter 调用 cancel]
    F --> G[设置 cancelled = true]
    G --> H[恢复 writer 协程 resume]
    H --> I[清空 writers_]
    
    D --> J[遍历 readers_ 链表]
    J --> K[对每个 ReaderAwaiter 调用 cancel]
    K --> L[设置 cancelled = true]
    L --> M[恢复 reader 协程 resume]
    M --> N[清空 readers_]
    
    N --> O[清空缓冲区 buffer_]
    O --> P[结束]
    
    Q[被唤醒的协程执行 await_resume] --> R{isCancelled?}
    R -->|true| S[抛出 CancelledException]
    R -->|false| T[正常继续]
```
